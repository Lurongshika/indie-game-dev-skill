# 独立游戏开发助手 Skill

本仓库收录 `indie-game-dev`，一个面向个人开发者与小型团队的独立游戏开发 Skill。它帮助开发者把游戏想法拆解为可执行的规划、设计、实现和验证工作，并适用于 2D 与 3D 项目。

## 能力范围

- **制作规划：** 梳理核心循环、最小可玩版本、风险与里程碑。
- **项目架构：** 根据现有引擎与工程组织模块、状态、数据和存档。
- **玩家体验：** 规划主界面、玩法界面、暂停与设置的层次，以及引导、HUD 和按键绑定。
- **美术与内容：** 支持风格方向、角色与场景制作、游戏文本和本地化。
- **教程与代码迁移参考：** 按目标效果搜索 B 站与 YouTube 教程，整理简介或评论区中出现的 GitHub 项目；由用户选择后，再分析代码、版本、依赖、许可和迁移范围。
- **测试与交付：** 设计试玩检查、回归场景和发布准备，并明确哪些结论经过实际运行验证。
- **数学知识游戏化：** 协助把函数、几何等数学概念转化为玩家可以操作和观察的机制，例如通过调整函数参数改变关卡地形。数学公式、参数与计算结果需要由开发者核验。

## 使用方式

将整个 `skills/indie-game-dev/` 目录复制到 Codex 的 skills 目录，之后在 Codex 中使用 `$indie-game-dev` 调用。Skill 会根据任务读取 `references/` 中相关指南，无需每次加载全部资料。

## 设计约束

- 尊重用户选定的引擎、游戏风格、项目现状与创作决定。
- 通过关卡、实践和反馈帮助玩家理解玩法，避免无理由地在游戏画面中堆放说明文字。
- 界面保持清楚层次；设置界面集中显示项目支持的操作按键，游戏内提示跟随当前绑定更新。
- 用户选择教程参考项目后再分析迁移；只有用户进一步要求实现时才修改其游戏工程。
- 区分已验证结果与待验证事项；无法运行引擎时不声称通过实际试玩。
